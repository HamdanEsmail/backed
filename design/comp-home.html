How a search runs

  1. First it finds companies like yours.

    TinyFish TinySet searches the live web for early rounds since May 2025 and returns each company with its investors and a link.

  2. Then it checks every link.

    TinyFish Fetch opens each announcement and looks for the names. A company whose page does not name its investors is set apart, with the reason.

  3. Last it adds up the backers.

    Every point is shown beside the sentence that earned it, so you can argue with the order.
